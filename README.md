# DOS USB

**Your entire MS-DOS childhood, in one app. Browse a library of 10,000+ classic games, click once,
and you are back in 1994.** 🕹️

DOS USB is a modern, good-looking launcher for the golden age of PC gaming. It pulls together a huge
catalogue of DOS games from across the web, hands you a clean store to browse them, and plays them
instantly in DOSBox - no manual config, no fiddling with mount commands, no rabbit holes. Pop it on
a USB stick and carry your collection between machines.

> 🎮 **Runs on Windows, Linux, and macOS.** Same app, same library, everywhere.

## Why you'll like it

- **10,000+ games at your fingertips** - aggregated from four trusted DOS archives, deduplicated,
  and searchable.
- **One-click play** - pick a game, hit play, and DOSBox is launched and configured for you.
- **A store that feels good** - sort by most popular, top rated or A-Z, filter by category, and skim
  screenshots, ratings, sizes and publishers at a glance.
- **Truly portable** - designed to live on a USB stick and travel with you.
- **Respects the originals** - this app ships _metadata and links only_; games are fetched on demand
  from their source, never mirrored here.
- **Fast and modern** - a virtualised grid keeps thousands of titles buttery smooth.

## Quick start

1. Grab the latest build from the [Releases page](https://github.com/webbertakken/dos-usb/releases).
2. Make sure DOSBox is available (see below - one line on each OS).
3. Open the app, browse the store, click a game, and play. That's it.

## Getting Started

### Prerequisites

The app runs on **Windows, Linux, and macOS**. It locates DOSBox per platform:

- **Windows**: uses the bundled portable DOSBox (`bin/DOSBoxPortable`), or any `dosbox` on `PATH` as
  a fallback.
- **Linux**: install a DOSBox from your package manager so one of `dosbox-staging`, `dosbox-x`, or
  `dosbox` is on `PATH` (e.g. `sudo apt install dosbox-staging` or `sudo apt install dosbox`).
- **macOS**: install via Homebrew, e.g. `brew install dosbox-staging`.

DOSBox is discovered in the order `dosbox-staging` -> `dosbox-x` -> `dosbox`. If none is found,
launching a game reports a clear error with an install hint instead of failing silently.

### Installation

#### For Users

1. Download the latest release from the
   [Releases page](https://github.com/webbertakken/dos-usb/releases)
2. Extract the contents to your USB drive (or anywhere you like); downloaded games are stored in a
   `games` folder beside the app
3. Launch the app:
   - **Windows**: run `DOSGamesPortable.exe`
   - **Linux / macOS**: run the bundled app for your platform

#### For Developers

The project uses Yarn (via [mise](https://mise.jdx.dev)). Clone and run:

```bash
yarn install
yarn electron-dev   # Next.js dev server + Electron, hot-reloaded
```

## Usage

### My Games

The home screen displays all your installed DOS games. You can:

- Search for games by title, description, or category
- Launch games with a single click
- Edit game metadata like title, description, and image

### Game Store

The Store tab lets you browse and download from a library of **10,000+ classic DOS games**,
aggregated and deduplicated across four archives:

- Sort by Most popular / Top rated / A-Z
- Filter by category and search by title, description, or tag
- See ratings, file size, publisher, and a screenshot
- Open a game's detail view for the full description and provenance
- Download games directly to your collection, then play them in place

#### Rebuilding the catalogue

The catalogue (`public/catalogue.json`) and screenshots (`public/screens/`) are generated by a
scraper:

```
yarn scrape          # incremental; re-run to refresh
yarn scrape --force  # re-fetch everything
```

The scraper records, per game, the preferred DOSBox-ready download, file size, full description,
rating, tags and the executable to run.

### Sources, attribution and takedowns

The library aggregates game metadata from multiple sources and credits each on every game ("Listed
on ..."):

- [DOSGames.com](https://www.dosgames.com) - curated metadata, screenshots and DOSBox-ready
  downloads.
- [Internet Archive](https://archive.org) - the MS-DOS games collection (download counts, in-browser
  play).
- [Abandonware DOS](https://www.abandonwaredos.com) - curated metadata, screenshots and ratings.
- [DOS Games Archive](https://www.dosgamesarchive.com) - curated metadata, screenshots and direct
  DOSBox-ready downloads.

The build currently yields ~10,400 games across these four sources (~2,700 listed on more than one).
Refresh a scrape-only source with `yarn ingest <abandonwaredos|dosgamesarchive>`, then
`yarn build-library`.

This repository stores **metadata, provenance and links only** - it never bundles or mirrors
copyrighted game binaries; those are fetched on demand from the originating source. Screenshots from
dosgames are cached locally; Internet Archive thumbnails are hotlinked.

Rights holders: to request removal of a title, add its canonical id to `scripts/data/denylist.json`
(or open an issue) and rebuild - denied games are excluded from the library.

Rebuild the aggregated library with `yarn build-library`.

### End-to-end verification

With a dev server running (`yarn dev`), `yarn e2e` launches the real Electron app, loads the store,
downloads a game and launches it in DOSBox - a full cross-platform smoke test. After
`yarn electron-pack`, `yarn e2e:packaged` runs the same checks against the packaged app.

### Settings

Configure your DOS USB environment:

- Set custom DOSBox path
- Set custom games directory
- View application information

## Building for Production

To build the application for production:

```bash
yarn electron-build
```

This creates a portable build in `dist/` that runs directly from a USB drive: `DOSGamesPortable.exe`
on Windows, `DOSGamesPortable.AppImage` on Linux. See [Packaged app](./docs/electron/packaging.md)
for how it serves the static export.
